# 研究计划：语义意图驱动的多 UAV 协同强化学习

## 核心研究问题

自然语言表达的高层任务意图，能否通过具有语义结构的表示注入多智能体策略，在未见意图、风险变化和动态任务切换条件下，提高 UAV 群体的安全—效率权衡与重规划能力？

## 当前证据边界

当前仓库已经具备连续动作 I-MAPPO、UAV 调度环境、风险分档、多 seed 自动运行和意图切换评估。但旧版“semantic library”使用文本哈希生成随机单位向量，因此只能证明稠密确定性码本的作用，不能证明自然语言语义的作用。当前正式实验还缺少完整消融、强连续动作基线、可靠统计和高保真验证。

## 目标贡献

### C1：语义结构化的意图条件策略

使用冻结的预训练文本编码器构造意图表示，并显式区分：

- one-hot；
- 随机稠密码；
- legacy hash 码；
- 预训练语义 embedding；
- 可选的可训练投影层。

必须通过同义改写、未见意图和组合意图测试证明语义结构带来的增益。

### C2：意图一致的安全多智能体优化

高层意图同时条件化 actor、centralized critic 和势函数奖励。训练过程中，意图标签、战术姿态、动作约束和环境奖励语义必须一致，避免随机意图与实际任务目标错配。

### C3：动态意图切换与风险泛化

在 easy/medium/hard 风险、不同机群规模、传感噪声、通信受限和动态目标条件下，评估安全、任务效率、能耗、重规划延迟和最坏分位性能。

### C4：可复现的 MARL 评估协议

使用真实且兼容的连续动作基线、完整消融、多 seed bootstrap 置信区间、IQM 和逐 seed 配对差异，公开所有配置与原始结果。

## 阶段门槛

### Phase A：研究可信性修复

- [x] hash 编码从 semantic 主实验降级为 legacy 对照。
- [x] 接入真实预训练文本编码器。
- [x] 修复意图与战术姿态错配。
- [x] 删除伪 QMIX/VDN 命名。
- [x] 建立统计评估和结果冻结流程。
- [x] 修复 true one-hot 身份基线。
- [x] 建立 held-out/paraphrase 无泄漏协议与确定性配对场景。

### Phase B：算法证据

- [ ] 完成 semantic、one-hot、random dense、MAPPO/IPPO 和全部消融。
- [ ] 完成 5-seed 泛化 pilot 并确定 embedding/projection 维度。
- [ ] 主结果至少 10 seeds；每 seed 每档至少 100 个确定性评估 episode。
- [ ] 报告 bootstrap 95% CI、IQM、成功率与 paired effect。
- [ ] 在至少两个标准 MARL 环境和一个 UAV 环境中验证。

### Phase C：泛化与真实性

- [ ] 未见意图、同义改写、组合意图。
- [ ] 4/8/12/16 UAV 规模迁移。
- [ ] 风、定位噪声、通信时延/丢包、动态威胁。
- [ ] 至少完成 PX4/Gazebo/AirSim SITL；条件允许时增加 HIL 或真机。

### Phase D：投稿冻结

- [ ] 冻结代码提交、容器、配置和数据清单。
- [ ] 自动生成论文表格与图。
- [ ] 完成方法、实验、局限性和复现附录。

## 投稿路线选择

- 算法路线：强化真实语义泛化、理论定义和多 benchmark，面向 MARL/ML 期刊。
- UAV 系统路线：强化动力学、通信、SITL/HIL/真机和工程约束，面向机器人、自动化或航宇期刊。

正式实验开始前必须选择一条主路线；另一条作为辅助证据，避免同时铺开但两边都不够深入。
